## 🍽️ 「今天吃什麼」Food Roulette v1.1.0

讓店家資訊對得上真實店家：店名去掉宣傳字詞、簡介頁改用 Google 的真實資料並可直接電話訂餐，抽籤頁也能依星等、價位、營業中與類型篩選。

### ✨ 新功能
- **抽籤頁篩選**：半徑旁的「篩選」可設定最低星等（3.5／4.0／4.5★ 以上）、消費級距（$～$$$$，可複選）、只抽營業中的店，以及餐廳類型（小吃、速食、咖啡廳、早午餐）；條件存在裝置上，只套用在抽籤頁。開啟星等、價位或營業中篩選時，沒有該項資料的店不會被抽到。
- **簡介頁顯示 Google 真實資料**：Google 地圖上的店家改顯示真實的星等與評論數、價位、營業時間、店家介紹與供餐資訊（內用、外帶、外送、素食等）；店家沒有提供的項目顯示「Oops，店家沒有提供該資訊」，不再用示範資料補。示範店與自訂餐廳維持示範資料並標示「示範資料」。
- **電話訂餐**：簡介頁的「預訂」改為「電話訂餐」，按下後開啟撥號畫面並帶入店家電話；沒有電話的店按鈕會停用。示範預訂改由多人抽的決勝卡片進入。

### 🛠️ 改善
- **精簡店名**：Google 地圖店名後方以 `|`、`｜`、`丨`、`│` 分隔的宣傳字詞（例如「|台中美食|必吃炸雞」）會被去除；已收藏的店與預訂紀錄讀出時也會套用，自訂餐廳與示範店的名稱保持不變。
- 同一間店的 Google 詳細資料在 App 執行期間只查一次；載入失敗可按「重試」。
- 沒有開啟星等、價位或營業中篩選時，附近搜尋維持原本的欄位與計費等級；類型篩選不額外計費。

### ✅ 測試
- JVM 單元測試與 Compose UI 測試全數通過，新增篩選、營業時間判斷、店名精簡、詳細資料快取，以及「多人決勝 → 預訂 → 我的頁」的端到端流程。
