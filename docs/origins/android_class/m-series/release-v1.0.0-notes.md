## 🍽️ 「今天吃什麼」Food Roulette v1.0.0

從單一抽籤畫面擴充成 10 個畫面的完整版本：收藏、多人抽、自訂定位、示範預訂、新增餐廳與分享都到齊了。

### ✨ 新功能
- **底部導覽 4 個分頁**：抽籤、收藏、多人、我的；切換分頁時主頁的抽籤結果會保留。
- **商店簡介**：店名、類型、距離，以及標示「示範資料」的評分、價位、營業時間、介紹與招牌菜；可收藏、預訂、分享或在 Google Maps 開啟。
- **收藏與從收藏抽**：收藏清單（首次啟動附 6 間台中車站附近的示範店），可只從收藏裡用拉霸滾輪抽一間。
- **多人抽**：4 位玩家各自按鈕抽籤（可同時按），「附近」池同一區域只查一次 Places，或改用「收藏」池；4 家都出來後按「決勝」選出一間。
- **自訂定位**：用車站預設點（台中／台北／新竹／台南／高雄）、點地圖或目前位置取代 GPS，主頁與多人「附近」池都會跟著改。
- **示範預訂**：選 14 天內的日期、時段、人數與訂位人，取得 `FR` 開頭的預訂碼；「我的」頁可查看與取消（不會真的送到店家）。
- **新增餐廳**：自己輸入店名、類型、備註與位置，儲存後自動加入收藏，收藏抽與多人抽都抽得到。
- **分享餐廳**：預覽訊息卡、加一句想說的話，透過系統分享選單傳給朋友，或只複製地圖連結。
- **我的**：暱稱、頭像顏色、收藏數、抽籤次數、有效預訂數與預訂清單（資料只存在裝置上，沒有帳號）。

### 🛠️ 改善
- 啟動時要求新版地圖渲染器，避免剛開機時地圖一直不回報載入完成。
- Places 地點類型固定以繁體中文顯示。
- 無障礙：加大頭像顏色等小元件的觸控範圍，圖示按鈕皆有說明文字；配色統一為 App 的暖色系。
- 所有資料存在單一 DataStore，損壞時自動回到預設值。

### ✅ 測試
- JVM 單元測試與 Compose UI 測試（含 3 條跨頁端到端流程）全數通過，並在 CI 的小螢幕模擬器上驗證。
